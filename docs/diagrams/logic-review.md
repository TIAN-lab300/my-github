## 与常见自适应学习平台比较

以 ALEKS、Carnegie Mellon OLI 为代表性参照，不将两者行为泛化为所有传统平台。以下“本项目”结论来自源码，比较判断为本次分析。

| 能力 | 代表性平台做法 | 本项目现状与差距 |
| --- | --- | --- |
| 内容与测评对齐 | OLI 以学习目标与组成技能组织教学、测评和分析 | 课程/知识点/题库关联已建；课程技能与目标图谱 ID 尚未审核映射，优先补齐 |
| 初始诊断 | ALEKS 使用个性化交互式知识检测建立知识状态 | 当前目标诊断发放固定题组；覆盖检查只校验目标技能有题，不代表每个递归先修都有足够题，也不代表自适应选题 |
| 掌握证据 | OLI 根据指定学习活动及测评作答估计目标达成；ALEKS 区分学习与知识检测后的掌握 | 已区分学习分钟与测验证据；但统一 BKT 参数与 0.75 阈值尚无各课程实证校准，两道题答对即可越过阈值，不能解读为可靠认证 |
| 再检测与补强 | ALEKS 后续检测更新知识状态，未保持的知识点重新加入学习路径 | 已有重测、掌握变化与补强逻辑；尚无周期性保持性检测、遗忘模型或到期复习调度 |
| 路径更新方式 | ALEKS 根据检测结果更新学习路径 | 当前学生主动生成并接受预览；对有时间预约的计划这是合理产品选择，并非逻辑错误，但需清晰提示需要调整 |
| 题目质量与曝光 | 有效诊断需要题目与目标对齐、足够覆盖和独立证据 | 已有审核与版本快照、部分曝光控制；尚不能据此认定难度、区分度、等价性和防记忆作答经过验证 |

## 影响实现的优先问题（本次仅记录，未改业务逻辑）

1. P1：课程库与目标规划库没有统一桥接。必须审核技能映射、适配三阶段题库、唯一同步证据并定义撤回重算规则，才能把课程成绩用于目标规划。
2. P1：先修未测不能等同已测薄弱。当前 evidence 标记 unknown，但确定性构建仍将缺证据的默认概率当作低掌握值安排学习；审查又要求执行技能有诊断映射。题库覆盖不足时应明确“先补测/补题”，不能仅依赖模型解释。
3. P1：修改目标会递增目标版本，而规划要求当前目标版本的已提交诊断；图谱变更也可能使原技能或测评映射失效。重新生成可能被阻断，需引导重新诊断或补齐映射；不能承诺点击重规划总能直接成功。
4. P2：BKT 跨班级累计同 ID 技能，缺少课程情境隔离与时间衰减。应确认技能确为同一能力，并制定证据最小数量、难度分层和参数校准，再用于正式验收。
5. P2：新增路径证据快照可检测测验及 checkins 的变化，但目标列表提醒没有完整覆盖所有来源/图谱/逾期变化，旧路径无快照也不能比较。执行时检查和用户可见提醒需一致。
6. P2：现有目标初测会读取活动图谱题库中其他技能的题目，并非严格只组目标及先修子集。建议限制范围，避免无关题量和无关技能证据。
