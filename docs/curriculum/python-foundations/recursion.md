## 1. 递归的两个条件
递归函数直接或间接调用自身。正确设计通常需要可直接返回的基本情况，以及让输入逐步接近基本情况的递归步骤。仅仅出现 if 或 return，并不保证能终止。
```python
def total(n):
    if n == 0:
        return 0
    return n + total(n - 1)
```
这个例子约定 n 是非负整数。total(3) 先等待 total(2)，再等待 total(1) 和 total(0)，最终返回 3 + 2 + 1 + 0，即6。负数输入不在约定范围内，不能指望它自动趋近0，应先验证输入或设计额外分支。

## 2. 基本情况与规模缩小
基本情况应返回与问题含义一致的值。阶乘在非负整数范围内使用 0! = 1；累加到0返回0。把所有基本情况机械地写成 return 0 会产生逻辑错误。规模可以是整数大小、列表长度或搜索区间；每次调用都应使它向终止条件推进。

## 3. 为什么需要 return
递归调用的返回值必须被当前层接收并用于计算或继续返回。只写 total(n - 1) 而没有把结果返回，不会自动把内层值传给外层。每一层的 return 只结束当前调用，尚未结束的调用还会继续计算。

## 4. 递归深度与迭代
递归深度是某时刻尚未返回的嵌套调用层数，不是整个程序累计调用次数。无限递归可能触发 RecursionError，栈空间和解释器限制都是约束；提高递归上限不能修复缺失的基本情况。对很长的线性累加，可优先用循环避免深层递归。本课不假设 Python 自动消除尾递归。
