# 原创基础题库：导入、对应关系与使用

## 本批范围

34门理论课程、357个知识点，每点初测、练习、重测各1道原创基础判断题，共1071题。另两门项目课程有20项提交任务与建议评分量规。题库完整定义保存在 `original-foundations-bank.json`，逐条断言和纠错依据保存在 `original-bank-claims.txt`，分课程数量见 `original-bank-coverage.md`。

这是AI辅助编写、经技术自检的项目基础题，**未经授课教师审核、未经难度与区分度标定，不是北理工官方试题**。三种用途采用不同断言，不能宣称为经过标定的等难度平行卷。二选一判断题只覆盖基础概念，不能代替编程、证明、综合计算和课程最终验收。

## 数据对应关系

`课程 → 章节 → 知识点 → 题目 → 不可变题目版本 → 试卷快照 → 作答 → 测验评价／知识点评价`。

课程与知识点使用真实 `public-Cxx` / `public-Cxx-Kxxx` 外键；章节通过既有 `learning_skill_chapters` 关联知识点，而不是把章节名硬写进题干。初测、练习、重测用独立题目标识。学生取卷接口在交卷前不返回答案或解析；交卷后计算成绩并记录知识点评价。重测排除已展示的题，即使没有交卷也算已见。绑定规划的课程还沿用跨测验的题目暴露检查。

## 导入与重复运行

在已有管理员、课程目录的本地安装上运行：

```powershell
.\.venv\Scripts\python.exe scripts/import_original_question_bank.py
```

脚本先备份数据库与附件，再迁移到0027并在单个事务内导入；结束后核对外键、数据库完整性、原账号班级资料测验记录及候选题数量。备份位置及结果在 `backend/data/original-bank-import-result.json`，不会上传真实数据库。其他独立安装可以指定 `--data-root`；首次安装仍需先初始化账号并导入课程目录。

`learning_bank_releases` 保存内容哈希与真实复核类型，`learning_bank_release_items` 追溯题目来源，`learning_project_rubrics` 保存项目任务。发布状态表示可以用于项目基础检测，不冒充教师批准：本批 `reviewer_id` 留空，来源说明与界面明确显示尚未经教师审核，导入审计主体为系统。用户已请求补齐可用题目；管理员可随后逐题停用不适合实际课堂的内容。

相同版本重复导入不会重复建题，不会改写学习记录，也不会重新启用已停用题目。同版本内容哈希变化会拒绝导入；修改已发布内容应创建新版本，以保留旧试卷快照。原15条待补全候选题保持原状，不混为本批1071道完整题目。

## 浏览器操作

学生登录 → 课程知识库 → 选择专业课程 → 选择测验用途 → 每知识点题数保持1 → 点击“选择可测知识点（最多30个）”或自行勾选 → 开始测验 → 选择正确或错误 → 提交 → 查看成绩、解析及知识点评价。未提交试卷可暂存并从历史恢复。

每点每用途目前只有1题。若改成每点2题，或对同一点用尽重测题，系统会明确提示不足；不会偷偷重用答案已见的题。后续需继续增加题量、计算与编程题、难度标定和教师复核。

项目课程页面显示每能力点的任务、提交材料、三项检查条件与0至3分等级。由教师根据实际证据评价；本批未新增在线项目交卷或自动评分接口，不把选择题成绩当作毕业设计验收结果。

## 验证范围

隔离测试逐一对34门课程的三用途组卷交卷，共102份试卷、1071份作答，检查课程及知识点映射、未交卷答案保护、成绩与评价、重测用尽、重复导入、停用保持和错配回滚。浏览器检查C语言三种用途实际出题交卷及两门项目课量规。自动验证保证数据与流程一致，不能替代授课教师对内容与教学适用性的复核。
