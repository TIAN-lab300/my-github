# 课程诊断与重规划桥接实施说明

实施日期：2026-11-15；数据库迁移 0024。本说明更新此前流程图审查中“课程证据尚未接入”的状态。

## 已实现的操作链

管理员在课程知识库录入并审核初测、练习、重测题，关联可检索正文；在“课程诊断与学习路径衔接”中，将课程知识点对应到当前审核图谱的等价技能。新技能须先通过现有知识图谱维护与审核流程，不能由模型直接激活。

学生选择目标知识点及其全部先修，完成课程初测并交卷。打开已提交的初测试卷，填写目标名称、截止日期和每周预算，点击“连接初测并创建目标”。系统冻结映射，将有效逐题作答转换为唯一 observations，建立已提交 diagnoses；随后进入“目标与诊断”生成本地或云端路径。

路径材料限定为本课程已关联且支持对应技能的当前有效正文；路径测验只使用本课程已发布练习题，申请复测使用本课程已发布重测题。课程测验、目标诊断与路径测验共享曝光信息，课程已绑定目标时避免重新发放已见题；缺题就提示补题。题目停用后不能继续提交包含它的路径或诊断测验。

绑定后，该学生在本课程新增的已提交测验，将相关映射技能的作答同步为规划证据，更新画像和重规划提示。每个课程试卷题目、每个学生的稳定题目身份最多同步一次；重复请求不重复增加证据。课程进度仍保留原课程评分和课程 BKT，规划画像单独从 observations 重放，不把两个概率相加。路径测验产生规划证据，不反向伪造一份课程试卷或课程总评。

课程阅读记录计入全局实际时间、目标执行证据及过期检查；阅读不增加掌握度。重规划继续保留已完成事实、生成候选、展示差异，接受时复查版本和预算后切换预约。没有当前版本诊断时页面引导“开始/查看诊断”；课程目标可以重新关联已评分初测，复用证据而不重复计分。

## 表与约束

| 表 | 用途与约束 |
| --- | --- |
| curriculum_graph_mappings | 课程技能 ↔ 图谱版本/技能，保留审核人与时间；同版本双向唯一 |
| course_goal_bindings | 目标绑定课程、图谱版本、映射快照和初测试卷；同份初测重复创建返回原目标 |
| course_evidence_attempts | 课程试卷 ↔ 规划作答记录，一对一 |
| learning_evidence_links | 课程试卷题 ↔ observation ↔ 映射；题目作答唯一、学生稳定题目身份唯一 |

不覆盖既有映射、不自动回填其他历史试卷。跨图谱版本复用技能编号也不能改为另一个课程技能，避免混合历史能力证据。当前不提供撤销映射或证据失效重算；需要改变语义时建立新技能编号并审核新图谱、重新创建目标。活动图谱版本变化后，旧绑定阻断新规划/新测验，历史记录保留。课程目标不能直接改写知识点集合；改范围需新初测和新目标。

## 接口与页面

- `GET /learning/courses/{id}/planning-readiness`：图谱节点、课程技能映射、三阶段题数、有效资料数、缺口与本人课程目标。
- `POST /learning/courses/{id}/planning-mappings`：管理员明确确认等价性，携带当前图谱版本，防止过期审核。
- `POST /learning/courses/{id}/goals`：学生从本课程已提交的 diagnostic 试卷建立目标。检查所有初测技能均有映射、全部先修已覆盖、练习/重测题已发布。
- 页面入口：课程知识库 → 选择课程 → 课程诊断与学习路径衔接。生成、接受、路径练习和重规划继续使用原目标/路径页面。

课程目标创建不代表材料、预算和云端配置已全部合格：生成阶段仍逐一校验正文支持、授权、排期及模型质量；缺口明确失败，不生成有效方案。

## 实现范围与限制

这是显式审核映射的首版闭环，不代表所有课程已经有审核内容。默认库不自动建立映射或发布候选题；管理员仍需为实际教学课程核准知识点、图谱、正文和题目。项目课程继续阻止以选择题代替教师量规。

本轮没有实现逐题自适应选题、题目难度/区分度校准、BKT 参数实证校准、时间遗忘模型、周期保持检测或自动调用收费模型。无证据先修会阻断并提示补测，不能被模型判为已掌握。图谱技能的规划证据仍按同学生同技能累计，映射的语义等价性必须由审核保证。

本轮不允许静默覆盖映射，因此不需要危险的历史重算操作；将来支持撤回时须单独设计失效账本、受影响路径和时间顺序重放机制。
