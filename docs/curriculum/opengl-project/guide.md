# OpenGL工程起步指南（项目原创）

本资料是实现任务与调试建议，不是完整可运行的渲染器。请先在工程设定记录操作系统、编译器、构建方式、图形上下文版本及依赖获取方式，并以真实机器的构建日志验证环境。

1. 建立最小工程，记录构建命令、运行命令及失败时的完整错误。
2. 创建窗口与图形上下文。实际窗口库、函数加载和平台链接参数由环境决定，不能直接把着色器片段当应用程序。
3. 准备三角形位置数据；顶点属性位置0应与triangle.vert的输入对应。先确认顶点数、属性布局、绑定及绘制调用，再定位黑屏。
4. 分别检查着色器编译与程序链接状态；先用固定颜色建立最小可见结果，错误日志也应提交。
5. 每次只加入一个变换、纹理或深度功能，记录可复现步骤和前后画面对比。
6. 最终交付源码或仓库地址、真实构建日志、截图/视频、运行步骤、测试结果与已知限制。画面与日志均由教师/管理员结合量规核对，系统不会把选择题或学生自报日志自动当成工程通过。

附带GLSL 330 core示例只适用于支持相应着色器版本且已建立上下文的程序，不包含窗口或资源管理代码。
