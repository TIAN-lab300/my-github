## 模型与数据选择

向量实现采用本地FastEmbed及SQLite持久片段。OCR采用RapidOCR，语音采用faster-whisper tiny及兼容的PyAV，媒体通过本地处理进程执行。该选择已同步四份主文档。复杂公式、图表、低质扫描及不同媒体编码的质量仍需扩大样本验证。

模型激活要求60场景报告全部硬判据通过，再由管理员逐例确认语义并填写依据。报告与配置绑定，不能通过JSON连通结果直接激活。迁移0017会将旧active配置转为approved待质量复核。

## 当前尚未完成的外部验收

1. 用户已选择暂不申请模型与搜索密钥。因此没有执行真实云端四Agent、Tavily或百炼搜索成功调用、配额验证和真实60场景质量评价。
2. 本机没有Docker。代码隔离适配器与正常任务入口已完成，真实镜像、越界程序、超时和资源限制仍需在Docker环境运行。
3. 独立电脑部署试用、实际参与人贡献及教学语义人工评分尚无真实记录。
4. 60个预置评价场景为函数、递归、调用栈的合成场景，不证明20个未预配置目标的泛化指标。
5. 知识覆盖的正文标题匹配与向量召回属于候选证据，不能替代教学语义确认。媒体时长无法读取时会保留未核验标记，不能宣称字幕时长已经验证。

这些项目没有登记为全部完成或100%验收通过。
