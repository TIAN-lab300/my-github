# 手机验证配置与验收

登录页面“显示密码”右侧为修改密码，可选择当前密码或短信验证；绑定手机号位于注册按钮下。

新增接口需对目标数据库备份后执行迁移并重启后端。当前8000旧进程未自动更新，切勿仅看到按钮就认为接口已部署。本批不自动迁移用户之前要求保留的8000数据库。

短信网关：在后端进程环境变量设置 SMS_GATEWAY_URL 和 SMS_GATEWAY_TOKEN。URL须HTTPS，后端发送Bearer认证请求，JSON为phone、code、expires_in=300；网关必须返回HTTP200及 {"accepted":true}。网关需由实际短信服务商适配并配置签名、模板。本项目不把验证码返回浏览器或写日志。

无真实凭据时发送应明确失败，不能声称短信到达。自动化后端测试使用替代短信发送器，仅验证业务链路与限制，不代表运营商送达验收。

本批验证：前端构建通过；backend/tests/test_phone.py 4项通过（未配置、绑定与重设链路/防复用、错误次数、过期与身份限制）；8000浏览器检查通过，包含改密右侧位置、手机号绑定/验证码表单入口。真实短信未验收，8000手机接口尚未部署。
