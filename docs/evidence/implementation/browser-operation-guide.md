# 知行平台浏览器操作与现场检验指南

适用日期 2026-11-06。当前手动验收地址为 http://127.0.0.1:9106/ ，使用独立演示数据库。已初始化Python示例班、资料和五个演示账号。也可自行注册学生与教师账号。

演示账号及一次性临时密码保存在 D:\卓越工程\backend\data\manual-review-20261106\accounts.txt 。预置账号首次登录必须修改密码。管理员由初始化取得，学生与教师可自助注册。

当前本地OCR、语音转写和向量模型可用。真实模型与联网搜索尚未配置密钥，Docker尚未安装。相关页面可以检查入口、授权和错误反馈，完整成功链需服务环境就绪。

## 1 同时操作三个身份

推荐教师使用普通窗口、学生使用另一个浏览器配置文件或另一款浏览器，管理员使用独立窗口。不同配置文件可保持各自会话，同一浏览器配置文件的普通标签页共享登录状态。

先用教师建班和发布资料，再用学生入班学习，最后用管理员检查权限、审计和配置。演示账号teacher与student已在同一示例班，可先用它们快速体验，再创建自己的账号测试完整流程。

## 2 登录 注册 密码和个人设置

| 检验内容 | 浏览器操作 | 应看到的结果 |
| --- | --- | --- |
| 自助注册 | 登录页点注册新账号，填写账号、姓名、学生或教师身份、两次密码，提交后返回登录 | 新账号可用自己设置的密码登录 |
| 重复账号 | 再次注册同一个账号 | 提示账号已被使用 |
| 首次改密 | 用演示文件中的临时密码登录，填写旧密码和两次新密码 | 完成后重新认证，进入对应工作台 |
| 显示密码 | 登录框勾选显示密码 | 输入内容保留并切换可见性 |
| 本人改密 | 页头修改密码 / 个人设置或左下角修改密码，填写旧密码与新密码 | 改密成功后重新登录 |
| 显示姓名 | 修改密码页面里的个人资料与学习设置，修改显示姓名并保存姓名 | 页头显示新姓名 |
| 学习偏好与预算 | 同页设置每日、每周分钟、时区、可学习日，点保存学习设置 | 保存后可重新读取，已有预览可能需要重新生成 |
| 忘记密码 | 查看登录页的管理员重置提示，请管理员重置该测试账号 | 临时密码需要首次修改 |
| 失败冷却 | 用专门测试账号连续输入错误密码达到5次 | 显示冷却时间，稍后再试 |
| 退出与多标签 | 登录后打开同配置文件的第二个标签，再退出登录 | 其他标签清理登录状态，受保护页面要求重新登录 |

不要把同一个测试账号用于冷却、停用和完整学习流程，以免前面的检验影响后面的操作。

## 3 教师建班 学生加入 成员管理

教师打开班级总览，填写班级名称与说明后创建班级。选择新班，点击编辑班级信息检查修改保存。

教师设置邀请码有效小时和使用次数，生成自定义邀请码后复制。学生打开我的班级，填写邀请码并加入班级，检查是否能看到对应课程与任务。

教师可查看和撤销邀请、移除成员。学生在个人资料与学习设置中退出班级。分别检查成员列表、课程访问和未完成任务状态。

检验晚入班补发时，先发布一份任务，再让第二名学生加入。教师到任务管理点创建指定学生补发草稿，选择该学生、建立补发草稿，核对未来截止时间后发布。

归档班级放到整套检验末尾操作。归档后检查历史记录能否查看，以及新邀请、发布和提交是否被限制。

## 4 教师课程知识库与学生私有资料

教师打开课程知识库，选择本班，点上传资料，填写标题、说明、标签、来源及使用权限，选择文件后提交资料并保存草稿。需要云端规划时，再明确选择允许必要正文发送云端。

学生也可在课程知识库上传私有资料，资料用于本人学习。教师课程资料与学生私有资料的可见范围分别保存。

可先建立一个UTF-8的TXT文件，正文填写以下内容。

```text
函数基础：Python用def定义函数，return返回结果，参数用于传入数据。
递归：函数调用自身，必须有结束条件，每次调用逐步趋向基本情况。
调用栈：保存每次函数调用的上下文，返回遵循后进先出。
```

| 文件或功能 | 具体操作 | 检验重点 |
| --- | --- | --- |
| TXT/MD | 上传后查看资料，再发布 | 正文可读、学生可检索 |
| DOCX/PPTX | 上传后等待解析，打开详情查看正文 | 段落、幻灯片及备注定位 |
| 文本PDF | 等待解析，查看资料 | PDF预览、页码与正文 |
| 图片/扫描PDF | 在详情点识别图片或扫描PDF，刷新状态 | 真实识别结果、失败原因、空白或未识别页提示 |
| 音频/视频 | 查看资料中的播放器，点自动转写音视频 | 处理任务、带时间段正文及质量分数 |
| 低分正文 | 在待复核版本里校正正文，确认复核正文 | 新版本进入草稿，审核后才发布 |
| 人工字幕 | 详情选择TXT/SRT/VTT，保存字幕版本 | 原始媒体保留，字幕产生新版本 |
| 字幕跳转 | 有时间段的正文中点定位到某秒 | 播放器跳到对应位置，点击播放 |
| 超长字幕 | 给一段短音频上传结束时间更长的字幕 | 已知媒体时长时应拒绝，未知时长会提示未核验 |
| 处理取消/重试 | 处理任务下点取消处理或重试此任务 | 状态持久保存，失败有原因，重试有次数限制 |
| 正文替换 | 正文版本管理上传新正文 | 产生新草稿，查看版本历史能看到旧版本 |
| 重新建立索引 | 正文就绪后点重建正文索引 | 可重新检索，重复执行结果稳定 |
| 重复上传 | 用相同内容和相同资料信息再次上传 | 返回已有资料，避免重复索引 |
| 发布/下架 | 在资料卡片上发布或下架 | 学生的新访问和检索跟随发布状态变化 |
| 筛选 | 组合选择班级、类型、发布状态、解析状态及标签 | 列表只显示当前账号有权查看的资料 |

文档与图片每份20MiB、合计100MiB，音视频每份200MiB，每批最多10份、合计500MiB。本地处理最长15分钟，媒体转写最长60分钟。浏览器无法播放某种编码时会提示下载或转码。

## 5 检索 覆盖缺口 联网和教师导入

学生进入资料检索与补充，教师进入知识库检索。填写递归，点击检索授权课程正文。

查看正文片段、来源位置和下载该来源版本。向量索引准备完成后，页面会显示已经使用本地中文向量。刚上传的资料可以等待几秒再检索。

再上传一张标题含递归、但尚未识别正文的图片，单独检索它的标题。页面应区分正文命中和仅资料信息命中。

需要外部资料时点搜索外部补充网址。当前会显示实时搜索尚未配置，这是本轮环境的实际状态。配置真实服务后，应显示本次返回的网址、来源域名、理由和未核实状态。

教师可以在推荐结果中选择收录班级，登记待审核网址，审阅网页并确认有权抓取后点审核并授权导入正文。之后回课程知识库查看草稿、核对正文并发布，学生再检索。

手工登记外部网址的入口也在教师课程知识库页面。单纯登记网址保留外部链接状态；完整授权抓取入口位于搜索推荐的收录流程。结构化覆盖、仅上传模式和时效窗口还有接口级判据，详细接口可在 /docs 查看，页面目前以缺口提示和目标可行性检查为入口。

## 6 学生目标 预算 诊断和历史

学生打开目标与诊断，规划方式先选择本地规则规划。

输入“每周3小时，在2026-12-01前学习Python函数和递归，偏好阅读文本”，点击解析目标描述，核对知识点、截止日期、分钟和偏好，勾选确认后保存目标。也可直接选择知识点并填写其他字段。

在目标卡片检查时间可行性、查看目标版本历史，使用修改目标检查修改后的新版本。全局时间预算与每个目标的每周预算分别设置，多个目标和教师任务共享可用时间。

点击开始/查看诊断，选择答案后暂存答案。刷新并重新打开，检查是否恢复。完成所有题目后提交诊断，查看反馈、掌握度和诊断历史。

在演示账号中可故意答错部分题，观察补强任务。全部答对可能减少待学习节点。

## 7 路径 接受 学习打卡与知识测验

完成诊断并准备足够的已发布资料后，点击生成首次路径，或到我的学习路径点击生成路径。

等待运行结束后点查看路径与差异，检查学习顺序、来源、先修规则、每天排期与预计分钟。点击接受此路径，系统保存活动路径和时间预约。

在可学习的节点点击记录完成，填写实际时间、完成比例、困难和备注。随后点知识测验与掌握验证，提交测验后刷新，观察掌握度与后续节点解锁状态。

掌握度达到0.75才会解锁依赖该知识点的后续节点。答对一次仍未达到阈值时，可在完成学习记录后领取等价重测，或完成教师的新测验继续积累证据。

运行面板可取消正在执行的运行、查看失败原因并重试。查看规划运行历史可重新打开已有运行与阶段记录。

## 8 重规划与等价重测

先接受一条路径，再修改预算、目标或完成部分测验。回我的学习路径点击生成重规划预览，再点查看路径与差异。

检查新增、移除、保留、补强、原排期、新排期与风险。接受此路径后，新版本成为活动路径；拒绝并保留原路径后，可继续查看原路径和风险提示。

若想检验过期预览，先生成预览，再改变目标、预算或资料版本，然后尝试接受旧预览，应提示重新生成。

完成一次该目标的路径学习记录后，打开原诊断结果，点补强后使用等价题重测。重测试卷与首次诊断不同，历史保留；当前等价题库用尽后会给出明确提示。

## 9 教师发布任务 学生作答 评分和补交

教师进入任务管理，选择班级，填写标题、说明、截止时间、预计分钟和接收人，保存草稿。预览接收人并发布，再确认发布任务。

| 任务类型 | 教师设置 | 学生操作和结果 |
| --- | --- | --- |
| 客观练习 | 设置题干、选项、正确序号和解析 | 暂存作答后恢复，提交后查看自动反馈 |
| 主观题 | 选择人工复核类型并填写题干 | 提交后显示待教师复核 |
| 文本/链接 | 设置任务说明，链接任务要求HTTP/HTTPS | 在提交内容填写文本或网址并提交 |
| 学习打卡 | 设置学习内容和预计时间 | 记录实际学习时间 |
| Python代码 | 展开代码任务测试用例，填写标准输入和预期输出 | 提交Python程序，查看测试结果及得分；当前环境会提示运行环境未就绪 |

学生到任务与反馈，可按状态筛选、查看关联资料、暂存、提交并查看反馈。重复提交成功的作答应返回同一记录。

教师在任务表格中查看提交。主观题填写0到1分和评分依据，保存后学生刷新查看。再次保存评分更正应保留历史评分版本。

需要补交时，教师创建指定学生补发草稿，核对截止时间后发布。撤回和关闭可以检查停止接收与分配状态，关闭或撤回后可创建修订版草稿再发布。

检验逾期时，可给专门测试任务设置几分钟后的截止时间，等待后刷新学生列表再提交，检查逾期状态及补交标识。

## 10 学习记录 学生画像与教师班级画像

学生进入学习记录，按日期、班级、类型等条件筛选和翻页，核对资料阅读、任务作答和路径打卡。

在学习概览或学习记录的完整学习画像中查看学习上下文、行为、掌握度、证据质量、风险和数据质量。点刷新当前画像、查看画像历史、查看刷新任务，检查时间和版本变化。

教师进入班级进度，选择班级查看完成率、学习时长、薄弱分布与风险数量。进入学生详情，选择本班学生查看授权画像。关联班级的目标和本班学习事实按权限显示。

## 11 管理员账号 审计和健康检查

管理员用账号文件中的admin登录并完成首次改密。到账号管理创建、筛选、分页查看教师和学生账号，检验停用、恢复和重置密码。可用独立学生窗口观察旧会话失效。

进入操作审计，按操作人、对象、动作、开始时间、结束时间和成功/失败结果筛选。用错误密码或越权操作产生失败记录，再查看对应审计。审计页面提供查询。

直接在浏览器访问 http://127.0.0.1:9106/api/v1/health 查看数据库、文件、模型、本地处理和搜索配置状态。

## 12 模型配置 四智能体与质量复核

管理员进入模型配置，登记模型、端点、密钥环境变量名、超时、令牌上限、温度和提示词版本。

服务端密钥就绪后，执行真实能力试验。再由运行命令执行60场景评价，在浏览器的质量评价与人工复核中查看每个场景、逐例确认语义、填写实际复核依据并批准报告，之后激活模型。

学生在目标或路径页将规划方式切换为真实云端四智能体。教师需先授予必要资料的云端使用权限。生成后检查运行阶段、计划说明、引用与预算，并确认页面显示云端生成。

当前没有真实密钥，完整成功链暂不可检验。可检查配置表单、未配置提示、激活门槛与权限提示。当前验收站点没有预置供应商质量通过记录。

## 13 新主题图谱和独立题库

管理员进入知识图谱，可以根据授权资料生成新主题草稿，也可展开登记新主题与独立题库，填写nodes和edges的JSON。

每个新知识点需具备diagnostic_questions、retest_questions、practice_questions三套不同题目。每题含id、skill、prompt、options、answer和explanation。answer使用从0开始的选项序号字符串。

登记后点查看图谱与题库，核对题目与先修关系，再启用图谱版本。学生刷新目标页面，应看到新知识点。启用会切换当前课程图谱版本，已有路径的练习题仍按保存版本读取。

可使用以下单节点演示图谱。先让教师在班级里发布包含“列表是有序序列，索引从0开始，可修改”的正文，再让学生创建列表目标进行诊断与规划。

```json
{
  "nodes": [{
    "id": "lists", "name": "列表", "minutes": 20, "aliases": ["list"],
    "diagnostic_questions": [{"id":"lists-d1","skill":"lists","prompt":"列表元素是否有顺序？","options":["有顺序","无顺序"],"answer":"0","explanation":"列表为有序序列。"}],
    "retest_questions": [{"id":"lists-r1","skill":"lists","prompt":"列表第一个元素的索引是什么？","options":["0","1"],"answer":"0","explanation":"Python列表索引从0开始。"}],
    "practice_questions": [{"id":"lists-p1","skill":"lists","prompt":"Python列表能否修改已有元素？","options":["可以","不可以"],"answer":"0","explanation":"列表是可修改的序列。"}]
  }],
  "edges": []
}
```

## 14 权限与异常的交叉检验

| 操作 | 检验结果 |
| --- | --- |
| 教师乙查看教师甲班级 | 被拒绝或不可见 |
| 班外学生查看、下载或检索班级资料 | 被拒绝或无结果 |
| 学生查看另一学生的目标、作答或画像 | 被拒绝 |
| 学生访问管理员账号或审计接口 | 被拒绝 |
| 发布后下架资料，再检索 | 新检索不再返回该正文 |
| 编辑时另一个窗口已保存新版本，再提交旧编辑 | 提示版本冲突 |
| 用过期或撤销的邀请码入班 | 显示失效 |
| 未完成诊断、资料不足或预算不足就规划 | 显示对应缺口，补齐后再生成 |

## 16 现场记录格式

每次记录账号身份、菜单、操作输入、预期结果、实际结果和截图。例如“学生甲／课程知识库／查找教师乙班级资料／无结果／实际无结果／截图”。遇到问题记录页面提示、发生时间和操作顺序，便于定位。

推荐检验顺序为注册登录、教师建班、学生入班、教师发布正文、学生检索阅读、教师发任务、学生作答、教师评分、目标诊断、路径学习、重规划、画像与审计，最后测试退班、停用和归档。
