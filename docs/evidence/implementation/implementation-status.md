## 已验证主线

登录与首次改密 → 教师建班与邀请 → 资源发布 → 学生阅读 → 教师任务 → 作答评分 → 真实记录与教师统计。另有目标 → 六题诊断 → BKT → 本地先修与预算规划 → 接受路径 → 学习测验 → 重规划预览/接受/拒绝。

后端14项集成测试通过，覆盖权限与CSRF、会话撤销、邀请去重、授权资源检索、阅读去重、提交前隐藏答案、真实评分、主观更正重放、路径版本冲突、缺证据拒绝正式路径、私人目标隔离、BKT公式、无模型密钥失败、路径测验去重、防环、发布后编辑限制、备份恢复与重启持久化。测试报告为backend-tests.xml。

浏览器首轮验证：三身份首次改密和登录、学生保存18分钟阅读、教师读取真实班级投影、桌面与390px手机宽度检查，无页面脚本错误或横向溢出。跨模块页面演练见browser-flow.json。

## 完成声明的限制

127项SF是最终功能清单，本版本未逐项验收，不声称全部完成。无密钥503只证明错误处理，不能证明真实云端成功。性能目标、60例AI评价、新主题泛化与他人电脑部署仍需实测。

当前为第三/第四周本地基础集成版。后续按SF补齐向量/联网、真实云端规划、完整子功能界面与持久刷新队列，不修改需求来隐藏未完成项。
