## 关键异常及复测

- 模拟审查阶段中断，重试仅续跑审查与保存，诊断阶段未重复；步骤历史保留失败及重试轮次。
- 构建阶段取消后无path、reservation提交，终态cancelled；取消的运行不能重试。
- 当日预算35分钟变25分钟，局部30分钟排期失败；基于已记录50%进度，全局补排15分钟成功，未改掌握证据。
- 来源下架和成员退出均使旧预览过期，返回409；其他目标预约与本目标完成预约保持原状。
- 篡改附件或数据库拒绝恢复，目标目录不存在；离线重建索引更新哈希，配置仅存引用不导出环境密钥值。
- 页面脚本修正等待运行创建响应、定位未启用图谱版本和等待目标path_id显示，避免在旧候选上操作。
