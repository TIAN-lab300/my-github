# 知行平台当前功能清单与增补映射

整理日期 2026-11-06。依据本地四份主文档、实施计划v1.2和2026-11-04增补清单。旧107/127仅为旧版历史验收，当前集成版本不能继承该通过率。

本清单保留127个旧SF编号，增加15组REG、KB、EXT追踪入口。入口之间存在重叠，不把它们相加为142项；新增OCR、自动转写、人工复核、抓取等还需原子验收分解，当前新版总分母待确认。下文“已有”仅指源码中存在实现，逐项通过需对应本轮证据。

## 各模块原有功能

### 登录与会话

- SF-AUTH-01 账号密码登录。系统应支持：有效账号和正确密码登录后进入对应工作台；无效凭据统一提示，不暴露账号是否存在。
- SF-AUTH-02 输入检查。系统应支持：账号去除首尾空白；密码不裁剪；空字段阻止提交，服务端再次检查。
- SF-AUTH-03 密码显隐。系统应支持：默认隐藏，可切换显示；切换不改变输入内容。
- SF-AUTH-04 提交防重与反馈。系统应支持：请求中禁用重复提交，失败解除禁用并保留账号，密码不写入日志或浏览器持久存储。
- SF-AUTH-05 首次登录改密。系统应支持：管理员设置临时密码后须先修改密码，完成前不能访问普通业务。
- SF-AUTH-06 本人修改密码。系统应支持：验证旧密码与两次新密码一致，成功后撤销全部旧会话并要求重新登录。
- SF-AUTH-07 忘记密码处理。系统应支持：提供联系管理员入口；管理员重置临时密码，系统不展示旧密码，不宣称提供邮件自助找回。
- SF-AUTH-08 当前身份与角色导航。系统应支持：刷新后由服务端查询当前身份生成导航，客户端不能通过切换角色取得权限。
- SF-AUTH-09 会话过期。系统应支持：失效请求返回401，页面提示重新登录，登录后仅跳转到该身份有权访问的站内地址。
- SF-AUTH-10 安全退出。系统应支持：退出撤销服务端会话并清理前端用户数据，浏览器后退不能读取受保护数据。
- SF-AUTH-11 停用与重置即时失效。系统应支持：账号停用或管理员重置密码后，所有旧会话下次请求立即失败。
- SF-AUTH-12 失败限流与恢复。系统应支持：多次失败进入可配置冷却，返回可重试时间，成功登录或冷却结束按规则恢复。
- SF-AUTH-13 跨标签页退出同步。系统应支持：一个标签页退出后其他标签页清理身份，服务器仍逐请求验证。
- SF-AUTH-14 认证审计。系统应支持：登录成功/失败、退出、改密、重置与越权记录时间和安全摘要，排除密码及原始token。

### 账号与个人资料

- SF-ACCOUNT-01 管理员初始化。系统应支持：仅受控初始化命令创建首个管理员，不开放公开管理员注册。
- SF-ACCOUNT-02 创建账号。系统应支持：管理员创建教师/学生，账号唯一，临时密码仅在创建或重置成功时交付。
- SF-ACCOUNT-03 列表与筛选。系统应支持：按角色、状态和账号查询，分页不泄露密码哈希。
- SF-ACCOUNT-04 资料编辑。系统应支持：本人修改展示名和允许的学习信息；账号标识、角色不允许自行修改。
- SF-ACCOUNT-05 停用与恢复。系统应支持：停用保留历史成果并撤销会话；恢复不恢复旧会话。
- SF-ACCOUNT-06 密码重置。系统应支持：管理员确认对象后重置，强制下次改密并留审计。
- SF-ACCOUNT-07 角色保护。系统应支持：不开放已有业务账号直接改角色，避免班级、任务归属失效。
- SF-ACCOUNT-08 误操作防护。系统应支持：停用和重置显示目标及影响并二次确认；初始化管理员恢复走受控操作而非公开接口。

### 班级与成员

- SF-CLASS-01 新建与编辑班级。系统应支持：教师设置名称说明，仅能编辑本人活动班级，保存检查版本。
- SF-CLASS-02 班级列表与详情。系统应支持：教师仅见负责班级；学生仅见已加入班级概况及本人关系。
- SF-CLASS-03 邀请码生成。系统应支持：设置有效期和使用上限，创建成功展示明文并支持复制。
- SF-CLASS-04 邀请码校验。系统应支持：无效、到期、撤销、耗尽或归档班级拒绝加入，提供明确提示。
- SF-CLASS-05 重复入班。系统应支持：同一学生重复加入返回原成员关系，不重复消耗邀请码。
- SF-CLASS-06 成员查询。系统应支持：教师查看本人班级有效成员和状态，学生不能浏览他人私密详情。
- SF-CLASS-07 退班与移除。系统应支持：退出或移除后取消未完成分配和未来预约；保留已完成历史但停止新增访问权限。
- SF-CLASS-08 班级归档。系统应支持：确认后转只读，撤销邀请码并禁止新发布和提交，保留历史查询。
- SF-CLASS-09 晚入班补发。系统应支持：不自动分配历史任务，教师可新建关联补发任务并明确接收人。

### 课程资源与知识库

- SF-RESOURCE-01 分类列表与筛选。系统应支持：按班级、类型、标签、标题、发布及解析状态查看授权资源。
- SF-RESOURCE-02 上传信息。系统应支持：填写标题、说明、标签、来源与使用权限、所属班级和云端授权。
- SF-RESOURCE-03 单批上传与失败反馈。系统应支持：逐文件显示成功失败；文本基线20MiB/文件、10文件/批、100MiB/批，超限拒绝且不发布半成品。
- SF-RESOURCE-04 格式校验。系统应支持：核对扩展名、MIME和内容；Markdown/TXT/文本PDF可解析，扫描PDF提示当前不支持。
- SF-RESOURCE-05 解析状态与重试。系统应支持：区分文件已保存、解析中、成功、失败，重试不产生重复版本或重复索引。
- SF-RESOURCE-06 版本与元数据编辑。系统应支持：正文修改创建新版本；引用绑定旧版本；元数据修改保留审计。
- SF-RESOURCE-07 发布与下架。系统应支持：仅所有者教师发布本班资料；正文检索型资源须索引成功；下架停止新访问与召回，历史引用按原授权快照读取。
- SF-RESOURCE-08 正文与下载。系统应支持：授权后阅读、下载，Markdown不执行脚本，文件真实路径不返回给用户。
- SF-RESOURCE-09 音视频与字幕。系统应支持：保留原型播放和字幕关联交互，字幕绑定版本；无字幕标待转写，不虚构自动识别结果。
- SF-RESOURCE-10 图片及其他附件。系统应支持：可作为授权附件存储预览或下载，未实现OCR/解析的资料标正文不可检索。
- SF-RESOURCE-11 网址登记审核。系统应支持：校验HTTP/HTTPS和标题理由，教师审核后发布；仅链接不算已验证正文。
- SF-RESOURCE-12 学生私有资料。系统应支持：学生上传私有资料用于本人学习；可见范围与云端发送权限分别设置。
- SF-RESOURCE-13 主动阅读记录。系统应支持：记录学习会话、实际分钟与完成状态；重复保存更新同一会话，不累计两次。
- SF-RESOURCE-14 附件发布边界。系统应支持：无正文的音视频/图片可作为附件发布；索引状态为不可用，不能进入正文RAG证据或伪装完成解析。

### 检索与证据

- SF-SEARCH-01 授权检索。系统应支持：召回前过滤班级/私有范围，查看来源及发送云端前再次检查授权。
- SF-SEARCH-02 混合召回。系统应支持：组合关键词与向量检索，返回真实chunk及页码/字幕时间定位。
- SF-SEARCH-03 结果解释。系统应支持：区分正文命中、仅元数据命中、无结果和证据不足，不把命中数量当覆盖结论。
- SF-SEARCH-04 覆盖检查。系统应支持：检查目标映射、节点、先修、学时、题目、证据，输出缺口类型。
- SF-SEARCH-05 联网开关与触发。系统应支持：本地完整且非时效不联网；仅上传资料模式有缺口时保留草稿。
- SF-SEARCH-06 来源验证。系统应支持：保存URL、标题、域名、支持片段、获取时间；未知日期用null，不伪造。
- SF-SEARCH-07 时效检查。系统应支持：固定概念与当前版本/近期事件分别验证；失败声明保留draft。
- SF-SEARCH-08 去重与补齐退出。系统应支持：相同来源合并并保留版本，最多两轮补齐，结构或预算错误不靠搜索解决。
- SF-SEARCH-09 无结果及外部失败。系统应支持：提示补充材料或重试，不将预置链接和模型记忆当实时搜索成果。

### 学习目标与预算

- SF-GOAL-01 目标增查改归档。系统应支持：多目标独立列表与详情，归档保留路径、作答和历史。
- SF-GOAL-02 结构化修正。系统应支持：自然语言解析为技能、截止、时间与偏好，学生可修正后确认。
- SF-GOAL-03 输入校验。系统应支持：拒绝空目标、非正预算和无效日期，无法理解时请求补充信息。
- SF-GOAL-04 全局时间设置。系统应支持：设置时区、可学习日、日周上限，目标预算不得重复占用全局额度。
- SF-GOAL-05 班级显式关联。系统应支持：目标默认私有，可关联本人一个班级，取消后不再展示教师详情投影。
- SF-GOAL-06 活动目标变更。系统应支持：时间或技能变化创建新版本并评估重规划，不覆盖当前路径历史。
- SF-GOAL-07 不可行说明。系统应支持：返回范围、时间、证据等冲突与可计算替代方向，不能虚报生成成功。

### 诊断测评

- SF-DIAG-01 题库与知识映射。系统应支持：题目包含题型、知识点、答案规则、解析、来源和不可变版本。
- SF-DIAG-02 诊断创建。系统应支持：默认6至12题，覆盖关键先修；不足节点显示低置信度。
- SF-DIAG-03 答题与暂存。系统应支持：显示进度和未答提示，草稿保存不产生评分证据。
- SF-DIAG-04 提交确认。系统应支持：按题目版本校验答案，防重复点击；答案在正式提交前不返回。
- SF-DIAG-05 结果反馈。系统应支持：显示正确错误、解析、知识点与初始化掌握度，保留诊断记录。
- SF-DIAG-06 重测与等价题。系统应支持：新建attempt并保留历史，使用等价题或先补强，避免背答案刷掌握度。
- SF-DIAG-07 无题或生成失败。系统应支持：明确缺口并保留可重试状态，不用占位题完成正式诊断。

### 学习路径

- SF-PATH-01 图谱维护。系统应支持：节点、技能、先修边和题目来源版本化，硬先修有环拒绝生效。
- SF-PATH-02 生成与运行恢复。系统应支持：创建新run，显示阶段、失败原因和重试入口，刷新可恢复查询。
- SF-PATH-03 候选与正式隔离。系统应支持：模型候选先校验；draft无法激活为正式路径。
- SF-PATH-04 先修与掌握度筛选。系统应支持：按目标闭包和有效掌握度生成待学节点，不因打卡自动跳过先修。
- SF-PATH-05 全局排期。系统应支持：所有目标和教师任务共用日周容量，按整数分钟计算，超限显示冲突。
- SF-PATH-06 路径规则审查。系统应支持：校验先修、时间、截止、负荷、重复节点和来源，保存规则结果。
- SF-PATH-07 解释与引用。系统应支持：展示为什么这样排序、学什么、多久、如何验收及来源定位。
- SF-PATH-08 路径接受与历史。系统应支持：确认后原子切换活动路径，每目标最多一条，旧路径只读。
- SF-PATH-09 任务拆解与解锁。系统应支持：任务带时长、日期、材料和验收方式，执行解锁取决于有效掌握证据。

### 教师任务

- SF-TASK-01 草稿创建编辑。系统应支持：包含标题、说明、截止、预计分钟、完成方式及关联资源，草稿可修改。
- SF-TASK-02 接收人选择。系统应支持：全班或指定本班有效学生，发布前预览分配范围。
- SF-TASK-03 发布冻结。系统应支持：发布时冻结内容及成员快照，不能原地修改答案、时长和截止。
- SF-TASK-04 学生待办筛选。系统应支持：显示未开始、进行中、完成、逾期和撤销状态，按截止排序。
- SF-TASK-05 文本链接打卡提交。系统应支持：学生只提交本人分配，成功即完成普通任务，主观测验评分状态独立。
- SF-TASK-06 逾期补交。系统应支持：允许补交，保存late和首次完成时间，完成不等于按时。
- SF-TASK-07 撤回与关闭。系统应支持：撤回取消未完成分配并释放未来负荷，关闭停止新提交，历史保留。
- SF-TASK-08 变更重发。系统应支持：发布后修改通过撤回再建新任务，保留前后关联，不能重写历史。
- SF-TASK-09 教师查看提交。系统应支持：仅本人班级可查看内容、状态和反馈，不能访问私人目标。
- SF-TASK-10 负荷联动。系统应支持：发布后占用截止前可用窗口，冲突产生重规划建议，不能直接改AI路径。

### 评分与反馈

- SF-ASSESS-01 客观规则评分。系统应支持：单选判断填空按版本化规则，多选默认全对得1其余0。
- SF-ASSESS-02 即时结果反馈。系统应支持：提交后展示得分、答案、解析、相关知识点和建议，反馈可历史查询。
- SF-ASSESS-03 主观待复核。系统应支持：简答/代码文本无确定性评分时pending_review，不伪装已判分。
- SF-ASSESS-04 教师rubric复核。系统应支持：教师对本班提交按公开rubric评分并备注，不执行用户代码。
- SF-ASSESS-05 评分更正。系统应支持：生成新评分版本与原因，重放有效观察序列，不重复增加掌握度。
- SF-ASSESS-06 证据去重。系统应支持：同attempt多次重试或更换幂等键仍只产生一次有效观察。
- SF-ASSESS-07 BKT更新与解释。系统应支持：记录前后概率、证据、参数版本和阈值，未测不等于薄弱。
- SF-ASSESS-08 打卡边界。系统应支持：时长正数、比例0至1，困难反馈与备注可存；阅读打卡不直接增加掌握度。

### 重规划

- SF-REPLAN-01 触发评估。系统应支持：掌握薄弱、连续两个任务到期未完成、预算/目标变化或证据冲突触发判断。
- SF-REPLAN-02 局部全局选择。系统应支持：范围变动、预算变化超过30%或局部不可行时按既有规则全局重排。
- SF-REPLAN-03 差异预览。系统应支持：展示原新节点、排期、补强任务、风险、依据和规则结果。
- SF-REPLAN-04 接受原子切换。系统应支持：重新核对目标、掌握度、成员和预算版本，仅替换本目标预约。
- SF-REPLAN-05 拒绝与风险保留。系统应支持：拒绝不改变原路径，保留风险提醒和先修执行限制。
- SF-REPLAN-06 陈旧预览拒绝。系统应支持：输入变化返回409并提示重新生成，不接受过期方案。
- SF-REPLAN-07 补强保留历史。系统应支持：创建独立补强task，不重复插入相同路径知识节点，不删除已完成事实。

### 学习记录与画像

- SF-PROFILE-01 本人记录筛选。系统应支持：按时间、目标、班级、资源和任务查看本人阅读、作答、反馈与路径记录。
- SF-PROFILE-02 进度分层。系统应支持：阅读完成、任务提交、知识掌握分别显示，不互相替代。
- SF-PROFILE-03 确定性统计。系统应支持：实际时长源事件去重，完成率和按时率使用既有分母，分母0显示暂无数据。
- SF-PROFILE-04 学生完整画像。系统应支持：展示上下文、行为、掌握、证据、风险及数据质量，仅本人可访问。
- SF-PROFILE-05 班级画像。系统应支持：统计授权班级完成率、时长、掌握分布、共性薄弱和风险原因。
- SF-PROFILE-06 学生授权投影。系统应支持：教师仅看本班证据和显式关联目标，排除私人目标与隐藏备注。
- SF-PROFILE-07 刷新与水位。系统应支持：事件变化生成新不可变快照，同水位不重复生成，失败保留旧快照标stale。
- SF-PROFILE-08 画像历史。系统应支持：查询窗口、版本、生成时间和依据，旧版本不被刷新覆盖。
- SF-PROFILE-09 解释与无数据。系统应支持：风险附原因与观测时间，LLM只能解释确定性数字，未知不写成薄弱。

### 四智能体与模型配置

- SF-AI-01 配置版本。系统应支持：保存模型端点、名称、生成搜索参数、超时及提示词版本；界面不返回密钥。
- SF-AI-02 能力试验。系统应支持：检查认证、结构化输出和实际搜索能力，保存真实结果，不假定供应商支持。
- SF-AI-03 评估后激活。系统应支持：只有评估通过配置可激活，失败回退上一有效配置。
- SF-AI-04 四Agent路由。系统应支持：诊断、路径、审查、重规划职责明确，工具调用经过业务服务与授权。
- SF-AI-05 执行追踪。系统应支持：保存run/step、输入版本、脱敏输出、工具调用、时间及错误。
- SF-AI-06 有限修复。系统应支持：非法JSON最多修复2次，规划最多修复3次且受总时限约束，失败不写半成品正式业务。
- SF-AI-07 取消重试恢复。系统应支持：保存检查点，中断可重试；取消阻止后续步骤和最终业务提交，已提交事务不假称回滚。
- SF-AI-08 云端隐私授权。系统应支持：发送文本/嵌入前检查cloud_allowed，未授权使用本地处理或提示缺口。
- SF-AI-09 服务异常。系统应支持：区分密钥无效、配额、限流、超时和搜索失败，基础学习链仍可用。

### 运维与交付

- SF-OPS-01 审计筛选。系统应支持：按操作人、对象、时间和结果分页，普通用户不能改删审计。
- SF-OPS-02 演示初始化与重置。系统应支持：受控命令可重复执行，危险重置确认并留审计，不开放学生一键清库。
- SF-OPS-03 健康与配置检查。系统应支持：报告数据库、文件目录与模型配置状态，不输出秘密。
- SF-OPS-04 备份一致性。系统应支持：备份数据库、附件、配置引用及版本清单，索引可重建，秘密另行受控交接。
- SF-OPS-05 恢复与验证。系统应支持：在隔离目标恢复并核对记录、附件及索引，不直接覆盖正在运行数据。
- SF-OPS-06 安装使用说明。系统应支持：提供初始化、启动、角色账号交接和故障排查，他人可按说明运行。
- SF-OPS-07 验收证据与贡献。系统应支持：记录输入、预期、实际、版本、失败复测、个人贡献和AI使用，不将计划写成完成。
