# 2026年11月6日增补功能实现与验证记录

## 范围与统计

本轮按四份主文档、实施计划v1.2和REG、KB、EXT增补重新核对范围。旧107/127为历史快照。保留127个SF编号和15组增补入口，入口存在重复，不据此计算142项或公布新版通过率。逐模块完整列表见[当前功能清单](current-function-inventory.md)。

## 已完成的代码变更

- DOCX按真实段落提取正文，包括表格中的段落。
- PPTX按presentation关系记录的实际演示顺序提取文字与演讲备注，保留幻灯片号。
- Office ZIP解压规模检查，拒绝不支持的XML声明，损坏文档进入解析失败状态。
- PDF正文保留真实页码，扫描PDF无正文时明确失败。
- Office首次上传使用已有持久解析队列，复用版本、发布门控和检索权限。
- 修正WAV常见MIME兼容，增加M4A与MOV附件及容器头检查。没有执行编解码或时长度量，不代表所有编码均可播放。
- SRT/VTT校验编码、文件头、时间格式、开始时间顺序、结束晚于开始和正文非空，失败时不产生字幕版本。TXT不虚构时间。
- 字幕正文保留起止秒数。尚未实现媒体时长自动校验和点击播放器跳转。
- 检索返回原始正文片段与最近结构定位，避免展示分词后插空格的全文索引内容。
- 搜索页显示定位及绑定资源版本的来源下载，历史下载复用原有历史来源授权。
- 所有者可按资料版本重建当前就绪正文的全文索引，原子更新、不产生重复命中，并保存审计。
- 上传与版本替换页面增加Office格式入口。四份主文档同步增补范围，旧台账增加历史状态提示。
