# 候选路径预览跳转修复

“查看生成路径”此前只加载数据并切换页面，路径预览位于运行记录上方，页面仍停在底部，重复点击同页也没有明确定位。统一openPath入口，加载完成后将焦点和滚动定位到“学习路径预览”；等待目标列表刷新完成后再定位，避免布局变化导致错位。规划成功、历史运行恢复和路径列表按钮共用入口。接受路径直接由明确按钮提交，不再依赖内嵌浏览器可能屏蔽的原生确认弹窗。

验证：TypeScript/Vite构建通过；Edge模拟接口浏览器验收通过，涵盖长运行记录下打开、同页重复打开、焦点与滚动、接受后活动状态、无原生弹窗和无页面脚本异常。测试未修改正式数据库或调用模型。浏览器Ctrl+F5刷新后即可使用，无后端代码变更。
