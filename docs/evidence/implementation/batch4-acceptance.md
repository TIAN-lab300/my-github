## 问题与复测

- 页面测试曾把下拉框选项文本计入标签，改用字段定位；诊断历史details也具有group角色，改为只遍历题目fieldset。
- 目标编辑的Schema错误统一转422；已完成预约在归档后保留，归档路径禁止新增打卡。
- 班级刷新失败曾缺少旧快照回退，并存在历史关联目标取消共享后仍可展示的边界，已补实现与故障注入验证。
- 旧诊断曾读取当前掌握度，改为提交时冻结；诊断历史状态在提交后自动重新加载，旧目标版本试卷不能继续提交。
