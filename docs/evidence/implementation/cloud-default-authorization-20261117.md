## 2026-11-17 资料云端授权默认策略更新

按用户明确要求，新上传文件、新收藏链接、公开课程导入、Python讲义导入及演示资料默认 cloud_allowed=true；后台资源插入公共入口也以true补齐未指定值。个人、班级、校级可见范围不变。允许用户在上传时取消勾选或编辑时关闭；前端对未勾选显式发送false，避免后端默认true把取消操作误当成未指定。
